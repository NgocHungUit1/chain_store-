Tải dữ liệu

(File mẫu mới)
Chi nhánh nhập {{branch.name}}

Lưu ý :

- Các sản phẩm có cùng tên nhà cung cấp sẽ được gộp thành 1 đơn nhập hàng.

- 1 file có nhiều nhà cung cấp sẽ được tách thành nhiều đơn nhập hàng.

- 1 đơn nhập hàng có tối đa 100 sản phẩm.

- File mẫu đã đổi cách trình bày (vui lòng tải file mẫu mới nhất):

  + Cột nền vàng là bắt buộc cho hệ thống, đã dồn lên đầu file

  + Cột nền xanh cần cho liên thông Dược Quốc Gia (thuốc theo lô phải có Số lô, Hạn sử dụng)

  + Cột nền xám là không bắt buộc

  + Điền vào sheet Data nhap hang; các dòng ví dụ nằm riêng ở sheet Vi du

  + Cột giá bán nếu không điền thì: giá bán = giá vốn * 1.1

- File mẫu cũ vẫn nạp được bình thường, không cần làm lại file đang dùng.
